03

元数据 Schema

17 个字段，覆盖检索、过滤、重排、溯源、时效管理五个环节。其中 queries 与 authority 是农业 RAG 区别于通用 RAG 的两个关键字段。

字段必填作用
doc_id是全局唯一标识，格式「领域-主题-序号」，用于答案溯源与去重
title是条目标题，参与向量化与目录检索
domain_l1 / l2是分类路径，作为元数据预过滤条件
crop否适用作物，避免「番茄问题召回大田方案」
region否适用区域，施肥量与播期存在强地域差异
stage / operation否生育期与农事环节，支撑「什么时候做什么」类查询
keywords是专业检索词，供 BM25 召回，均值 7 个
queries是用户口语化问法，供查询扩展与相似度对齐，均值 4 条
content是正文，单条 200–500 字即一个 chunk
source是来源标注，覆盖率 100%
authority是权威等级，结论冲突时按此仲裁而非相似度
stability是稳定 / 年度更新 / 时效性，决定缓存与下架
confidence是高 / 中 / 低，低置信度条目在生成时降权
risk_level是风险分级，高风险强制附安全提示
valid_from否时效性知识的生效时间，到期自动降权
version是条目版本，支持 diff 与历史回溯
04

建库路径

不要先追条目数量。先用 100 条跑通「检索—重排—生成—溯源」闭环，验证切分粒度，再扩量。

01
清洗切分
按 【条目】 标记切，前缀拼「作物·主题」
02
向量化
BGE-M3 或同类中文模型，content + queries 一起编码
03
混合召回
BM25 攻专业词，向量攻口语，两路合并去重
04
重排加权
Rerank 后按权威等级、时效、风险二次加权
05
生成约束
数值带出处、高危前置警告、低分拒答
评估目标：Recall@5 ≥ 0.85　·　MRR ≥ 0.70　·　答案忠实度 ≥ 0.90　·　高危项（农药剂量 / 间隔期 / 禁用名录）错答率 0
